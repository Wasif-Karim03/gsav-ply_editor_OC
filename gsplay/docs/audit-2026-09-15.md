# GSPlay + gs-encoder v3 audit — September 15, 2026

## Result

The tested local Windows/CUDA pipeline works from GSAV upload through editing,
standard PLY/GSAV export, and playback in the available OpsiClear WebGL2 viewer.
This verifies the workflows below, not every file, setting, or hardware platform.

## Defects fixed

1. **CPU edits could disappear on export.** Native processing replaced Gaussian
   fields while retaining an old packed buffer. Transform, opacity, and CPU
   color boundaries now invalidate that buffer. Ten regression cases cover five
   CPU/GPU modes with RGB and SH3, checking translation, scale, brightness and
   opacity together against exported values.
2. **Invisible points could become faintly visible.** PLY normalization clamped
   zero opacity. Export now preserves the negative-infinite opacity logit, and
   v3 encoding interprets it as an absent slot, combined with any explicit mask.
   A real two-frame round trip preserves eight invisible and 24 visible points.
3. **Scene replacement retained resources or stale metadata.** Replaced PLY
   sources now shut down, unused upload directories are released, and config
   loading/unloading clears GSAV metadata. Reload retains the active upload.
4. **Test setup was stale.** Fixed obsolete module imports, replaced a local
   folder dependency with temporary PLY fixtures, and use real installed Viser.

Direct GSAV-to-array import and separate v3 codec environments remain intact.
No dependency versions were changed.

asserted tolerances. GSAV is lossy and spatially reorders points. Nearest-position
comparisons estimate mean RGB errors of 0.000114 and 0.000106, and SHN errors of

or exact identity comparisons. Frame 0 has 27,181 unique matches for 27,184 points

matches and maximum distance 0.00158.

## Limits and outstanding verification

- Twenty-five old GSPlay tests return booleans instead of asserting outcomes.
  Pytest counts these as passes regardless of their return values. Do not count
  those 25 as reliable evidence; the remaining 70 tests and explicit browser,
  numerical and integration checks provide the functional coverage above.
- Parent `npm test` is not green: 49 passes and 76 failures. Its broad discovery
  includes unrelated TypeScript viewer snapshot tests under `outputs/`. These
  are separate from the GSPlay and encoder Python suites.
- The encoder skip is an optional renderer test. GSPlay rendering and the
  independent WebGL2 viewer were checked separately.
- Folder-picker logic has existing automated coverage. The native Windows
  dialog was not manually selected/cancelled during this audit. It selects on
  the server device, not a remote browser device.
- Standard PLY and GSAV are the verified exports. Legacy Compressed PLY is
  separate and is not the SH-preserving export path evaluated here.
- Very large files, long-duration resource usage, other operating systems,
  CPU-only rendering, every filter/color combination, and other viewer backends
  were not exhaustively tested. Existing audio/static-track limitations in
  `gsav-integration.md` still apply.
